# Student Grade Calculator

## Project Description
Student Grade Calculator is a beginner-level Python project that calculates students' total marks, percentage, grades and pass/fail results.

## Features
- Accepts multiple student details.
- Accepts marks in five subjects.
- Calculates total marks and percentage.
- Assigns grades based on percentage.
- Checks individual subject passing criteria.
- Validates marks entered by the user.

## Technologies Used
- Python

## Concepts Used
- Variables
- Data Types
- Operators
- Conditional Statements
- Logical Operators
- For Loop

## Project Type
Beginner Python Project
